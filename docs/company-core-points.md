# 农场电商公司玩法核心要点提炼（V1）

## 1. 核心闭环
- 生产端：种植/养殖/收购三类供给路径。
- 加工端：基础加工到高附加值加工的分级扩展。
- 渠道端：直播、电商、多平台和线下体验联动。
- 组织端：岗位分工、村民协同、工资分红和激励。
- 共富端：就业带动、支持度提升、培训孵化与区域复制。

## 2. 核心资源与指标
- 资金：经营现金流和升级投入核心约束。
- 微粒/生命源能：系统能力与自动化功能的解锁货币。
- 村民支持度：影响招募效率、升级和共富分支。
- 品牌热度：影响溢价能力、渠道能力和合作机会。

## 3. 版本化升级路线（1-5级）
- Lv1 初创期：注册公司+基础直播售卖+基础组织搭建。
- Lv2 成长期：加工扩展+多平台运营+财务岗位。
- Lv3 规模化期：品牌化运营+团队化执行+科研联动。
- Lv4 区域标杆期：线下拓展+外部合作+供应链扩张。
- Lv5 共富标杆期：产业复制+培训孵化+终局剧情解锁。

## 4. 操作哲学（躺平友好）
- 决策优先：玩家做方向和策略，系统处理重复执行。
- 风险可控：市场、自然、运营、资金四类风险预警。
- 即时反馈：每次行动都有收益/风险/关系的直接结果。

## 5. 本轮实现映射
- 主页：重构为“公司驾驶舱”，呈现闭环模块、阶段路线、执行入口、设计要点。
- 个人中心：重构为“治理中台”，聚合主角档案、经营指标、升级路线、参数策略。
- 后端：新增 company_design 计算模型，统一驱动页面渲染和后续扩展。

## 6. 后续扩展建议
- 将支持度、品牌热度从派生值升级为真实可持久化数值。
- 引入合作对象状态机（科研/政府/企业/村集体）作为独立模块。
- 将加工品类和渠道等级做成可视化树，和公司等级联动解锁。
