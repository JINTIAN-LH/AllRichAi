## 组件详细设计

### 1. UI组件层

#### FarmDashboard.html
- **职责**: 农场可视化展示和操作
- **输入**: 游戏状态数据
- **输出**: 用户操作事件
- **依赖**: 
  - base.css (基础布局)
  - panel.css (面板样式)
  - farmInteract.js (交互逻辑)
- **关联组件**: 
  - StatusBar.html (状态信息)
  - AnimEngine.js (动画效果)

#### WarehousePanel.html
- **职责**: 库存管理和物品操作
- **输入**: 库存数据
- **输出**: 物品使用/出售事件
- **依赖**: 
  - panel.css (面板样式)
  - warehouseInteract.js (交互逻辑)
- **关联组件**: 
  - FarmDashboard.html (物品使用)
  - StatusBind.js (状态更新)

#### TaskPanel.html
- **职责**: 任务展示和管理
- **输入**: 任务数据
- **输出**: 任务完成事件
- **依赖**: 
  - panel.css (面板样式)
  - taskInteract.js (交互逻辑)
- **关联组件**: 
  - StateSync.js (状态更新)
  - AnimEngine.js (完成动画)

### 2. 交互逻辑层

#### FarmInteract.js
- **职责**: 处理农场相关操作
- **主要方法**:
  - `init()` - 初始化农场交互
  - `handlePlotClick(plotId)` - 处理地块点击
  - `performAction(actionType, plotId)` - 执行农场操作
  - `updatePlotDisplay(plotId, status)` - 更新地块显示
- **依赖**: 
  - EngineBridge.js (API调用)
  - AnimEngine.js (动画效果)
  - StateSync.js (状态更新)

#### WarehouseInteract.js
- **职责**: 处理仓库相关操作
- **主要方法**:
  - `init()` - 初始化仓库交互
  - `switchTab(tabName)` - 切换物品类别
  - `useItem(itemId)` - 使用物品
  - `sellItem(itemId)` - 出售物品
- **依赖**: 
  - EngineBridge.js (API调用)
  - StatusBind.js (状态更新)

#### StateSync.js
- **职责**: 管理游戏状态同步
- **主要方法**:
  - `init()` - 初始化状态同步
  - `syncState()` - 同步最新状态
  - `addStateUpdateCallback(callback)` - 添加状态变更回调
  - `removeStateUpdateCallback(callback)` - 移除状态变更回调
- **依赖**: 
  - EngineBridge.js (获取状态)
  - 各个UI组件 (状态更新通知)

### 3. 动画效果层

#### AnimEngine.js
- **职责**: 管理各类动画效果
- **主要方法**:
  - `init()` - 初始化动画引擎
  - `triggerAnimation(type, element, options)` - 触发动画
  - `createCustomAnimation(config)` - 创建自定义动画
- **支持的动画类型**:
  - drag (拖拽)
  - harvest (收获)
  - plant (种植)
  - collect (收集)
  - upgrade (升级)
  - highlight (高亮)
  - pulse (脉冲)
  - floatUp (浮起)
  - floatDown (下沉)

#### ParticleEffect.js
- **职责**: 管理粒子效果系统
- **主要方法**:
  - `init()` - 初始化粒子系统
  - `createHarvestEffect(x, y, options)` - 创建收获特效
  - `createUpgradeEffect(x, y, options)` - 创建升级特效
  - `createRewardEffect(x, y, options)` - 创建奖励特效
- **特性**:
  - 粒子池管理 (复用DOM元素)
  - 随机轨迹计算
  - 缓动函数支持

### 4. 通信层

#### EngineBridge.js
- **职责**: 与后端引擎通信
- **主要方法**:
  - `executeAction(actionData)` - 执行游戏动作
  - `getState()` - 获取游戏状态
  - `saveGame(slot)` - 保存游戏
  - `loadGame(slot)` - 加载游戏
- **错误处理**:
  - 网络错误重试
  - 状态异常处理
  - 用户友好错误提示

## 数据流设计

### 状态更新流程
```
1. StateSync.syncState() → EngineBridge.getState()
2. EngineBridge → Flask API → 游戏状态
3. Flask API → EngineBridge (JSON响应)
4. EngineBridge → StateSync (解析数据)
5. StateSync → 触发所有注册的回调函数
6. 回调函数 → 更新相应UI组件
```

### 用户操作流程
```
1. 用户在UI上执行操作 (点击、拖拽等)
2. UI组件 → 调用交互逻辑层方法
3. 交互逻辑层 → 调用EngineBridge.executeAction()
4. EngineBridge → Flask API → 游戏引擎
5. 游戏引擎 → 执行操作并返回结果
6. Flask API → EngineBridge (结果响应)
7. EngineBridge → 交互逻辑层 (处理结果)
8. 交互逻辑层 → 更新UI显示
9. 交互逻辑层 → 触发动画效果
```

## 性能优化策略

### 1. 状态同步优化
- **增量更新**: 只更新发生变化的状态字段
- **防抖机制**: 避免频繁的状态同步请求
- **缓存策略**: 缓存最近的状态数据

### 2. 动画性能优化
- **硬件加速**: 使用transform和opacity属性
- **动画帧率**: 限制动画帧率为60fps
- **粒子复用**: 使用粒子池避免频繁DOM操作

### 3. 内存管理
- **事件清理**: 组件销毁时清理事件监听器
- **定时器管理**: 及时清理不需要的定时器
- **对象回收**: 避免内存泄漏
