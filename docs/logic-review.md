# 逻辑自检报告

## 结论

原始设计方向成立，但如果直接照文档实现，开局节奏、资源兑换和长期叙事会出现明显卡顿。当前原型已对这些点做了保守修正，使其能够先跑通一轮完整经营循环。

## 发现的问题

### 1. 开局地点与系统等级不一致

- 文档主线一开始，主角已经回到刘家村开始种田。
- 但源能场表格把高效率采集放在 Lv2 郊区，Lv1 仍然对应城市。
- 如果严格按表执行，回乡开局要么资源过低，要么剧情地点与系统状态不一致。

处理方式：原型默认从 Lv2 开始，等同于“回乡后系统进入乡野部署状态”。

### 2. 微粒兑换生命源能速度过慢

- 文档写明 `10000 微粒 = 1 点生命源能`。
- 同时开局日收益在 30 到 300 微粒之间。
- 这会导致第一卷大量系统能力无法在合理回合内解锁。

处理方式：原型将兑换率暂调为 `1000:1`，并保留任务直接奖励生命源能。

### 3. 二十年长线缺少时间压缩机制

- 文档覆盖从返乡到共同富裕的二十年过程。
- 但没有说明每一卷应该按日、按月还是按阶段跳时。
- 如果强行逐日模拟，文本游戏的节奏会非常拖。

处理方式：原型采用阶段制，只保留关键节点条件，避免机械刷回合。

### 4. 共同富裕目标没有量化判定

- 文档提出村民就业、公司化运营、缩小城乡差距等目标。
- 但没有定义多少就业、多少分红、多少公共建设算“达成”。

处理方式：原型增加 `prosperity` 指标，先用作共同富裕的代理变量。

### 5. 自由输入与固定玩法接口尚未统一

- 文档强调大模型自由探索。
- 但规则层仍然以固定菜单、固定任务和固定数值为主。

处理方式：当前先用稳定菜单验证规则，后续在 `engine` 之上接自然语言解析层。

## 当前实现中的保守假设

- 开局即处于刘家村，系统等级为 Lv2
- 起步阶段只模拟种植，不展开养殖和加工厂
- 用 `prosperity` 代理就业、分红、家庭修复和公共建设贡献
- 直播、电商、科研合作先做成收益和任务条件，不做独立子系统

## 建议的下一轮补强

1. 增加季节系统，避免所有作物全年可种
2. 把村办公司拆成招工、分红、订单、品牌四个模块
3. 为姐姐支线增加“听障辅助科技”独立研发线
4. 用事件图定义卷一到卷三的关键跳时节点
5. 接入大模型时，先限制在“建议动作”和“剧情润色”，不要直接绕过规则层
