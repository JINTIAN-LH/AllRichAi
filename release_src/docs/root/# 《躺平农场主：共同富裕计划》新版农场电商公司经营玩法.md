《躺平农场主：共同富裕计划》农场经营电商公司玩法设计文档

一、文档概述

1.1 设计定位

本玩法是游戏中期至后期的核心内容，承接“基础种植”“电商初步合作”主线，聚焦刘洋与王楠联手打造的农场电商公司，实现“农场种植→产品加工→品牌运营→电商销售→村集体共赢”的全产业链闭环。玩法兼顾“躺平”低压力特性与“经营”的策略性，既允许玩家依托系统实现轻量化管理，也支持深度运营打造区域标杆企业，最终服务于“共同富裕”的核心目标，同时联动现有角色、系统、资源体系，保证世界观统一性。

1.2 核心关联

- 关联角色：刘洋（农场端负责人）、王楠（电商端负责人）、杨大振（品种优化支持）、赵江新（技术支持）、刘怀均（村民协调）、村民（员工/合伙人）；

- 关联系统：躺平智辅系统（数据支持、功能解锁、风险预警）、生命源能/微粒体系（公司升级、功能解锁）；

- 关联玩法：基础种植、农产品加工、村民互动、科研合作、公益助农；

- 核心目标：从“小作坊式电商”升级为“规模化农场电商公司”，带动村民就业、增收，实现“个人创业+村集体共赢”，解锁后期共同富裕剧情。

1.3 适用阶段

游戏第二卷（五年创业，家业初成）至第三卷（二十载耕耘，共富成真），对应玩家完成“第一季作物收获+首次直播售卖”，具备基础农场规模、初始资金和电商渠道后解锁。

二、核心设定：农场电商公司基础框架

2.1 公司名称（可自定义）

默认名称：麓湖乡田电商有限公司（贴合刘家村所属麓湖市，突出乡村农场属性）；玩家可在公司注册时自定义名称，不超出“乡村、农场、农产品、电商”相关调性。

2.2 公司定位

以刘家村农场为核心供应链，聚焦“原生态、高品质、本地化”农产品，打造“农场直供+电商直播+品牌化运营”的乡村电商模式，兼顾“盈利性”与“公益性”——既实现公司规模化盈利，也带动村民就业、农产品上行，推动乡村振兴。

2.3 组织架构（可升级、可调整）

三、核心玩法模块（全流程闭环）

3.1 模块一：公司注册与初始搭建（1级解锁）

3.1.1 注册流程（轻量化操作）

1. 触发条件：完成第一季水果玉米直播售卖，王楠提出“注册公司、规模化运营”提议，刘洋同意后启动注册；

2. 核心操作：消耗10000元资金，选择公司名称，确认组织架构（默认刘洋、王楠为核心负责人），系统自动完成注册流程（无需手动操作复杂步骤，贴合躺平需求）；

3. 注册奖励：解锁公司面板、村民招募权限、基础电商店铺，王楠好感+20，微粒+50，生命源能+1。

3.1.2 初始搭建

- 场地：利用家里闲置房屋改造为简易办公区，农场作为生产基地；

- 设备：解锁简易包装设备（消耗2000元），系统提供基础包装模板；

- 人员：通过刘怀均招募3名村民（需支付基础工资，每日结算），分工为田间种植、包装、发货。

3.2 模块二：农场供应链管理（贯穿全等级）

核心逻辑：农场是电商公司的核心供应链，玩家可选择“自主种植”“村民合作种植”“周边村庄收购”三种模式，兼顾“躺平”与“规模”，由系统辅助管理，减少手动操作。

3.2.1 种植模式选择（玩家自主决策）

1. 自主种植：玩家主导农场种植，选择作物品种（系统推荐适配电商的品种，如水果玉米、小番茄、西甜瓜等），开启系统“自动灌溉、施肥提醒”功能，无需手动操作田间细节，只需定期查看生长状态，适合躺平玩家；

2. 村民合作种植：与村民签订合作协议，村民提供土地和劳动力，公司提供种子、技术指导，收获后按比例分成（玩家可自定义分成比例，影响村民支持度），玩家无需参与种植，彻底躺平，仅把控品质；

3. 周边村庄收购：公司等级4级解锁，收购周边村庄的优质农产品，扩大供应链，适合规模化运营，玩家只需把控收购品质和价格，系统自动完成收购流程。

3.2.2 品质管控（核心竞争力）

- 技术支持：杨大振提供品种优化、种植技术指导，消耗生命源能可解锁“高级育种”“绿色认证”，提升产品品质和售价；

- 系统检测：躺平智辅系统实时检测作物生长状态、加工品质，出现病虫害、品质不达标时，自动发出预警，并提供解决方案（玩家可选择系统自动处理，无需手动操作）；

- 品质分级：收获/收购后，系统自动将农产品分为“精品”“优质”“普通”三级，分级定价，精品用于直播爆款，普通用于批量售卖，提升盈利效率。

3.3 模块三：电商运营（王楠主导，玩家决策）

核心逻辑：王楠负责电商端具体运营，玩家只需做核心决策（如直播主题、定价、渠道选择），系统辅助统计数据、优化方案，贴合“躺平创业”理念，无需玩家手动操作直播、客服等细节。

3.3.1 电商渠道（随公司等级解锁）

1. 基础渠道（1级）：抖音小店、拼多多店铺，主打“农场直供”，王楠负责日常运营、短视频拍摄、直播带货；

2. 进阶渠道（2级）：淘宝店铺，新增“加工品专区”，打造品牌形象；

3. 高端渠道（3级）：社区团购、企业采购，对接省城企业、社区，批量售卖；

4. 终极渠道（4级）：全国电商平台、线下体验店，实现“线上线下联动”，覆盖全国市场。

3.3.2 核心运营玩法

1. 直播带货（核心）：

- 直播主题：玩家选择（如“农场采摘现场”“加工过程展示”“村民故事”“试吃测评”），王楠负责执行，系统根据主题生成流量加成；

- 直播优化：消耗生命源能解锁“直播流量加持”“爆款推荐”功能，系统自动优化直播话术、画面，提升转化率；

- 互动玩法：直播中可设置“秒杀”“满减”“抽奖”等活动，玩家决策活动力度，系统自动统计销量、结算收益。

2. 产品包装与定价：

- 包装设计：1级解锁基础包装，2级解锁定制包装（可印品牌LOGO），3级解锁高端礼盒包装，包装等级影响产品售价和复购率；

- 定价策略：玩家自主定价，系统提供“市场参考价”“成本核算”，定价过高影响销量，过低影响盈利，系统会给出优化建议（可选择自动定价，躺平首选）。

3. 客户维护：

- 王楠负责日常客服、售后，系统自动统计客户评价、复购率，出现差评时，自动提醒并提供解决方案（玩家可选择系统自动处理，或手动干预）；

- 会员体系：3级解锁会员体系，会员可享受折扣、优先发货、专属产品，提升复购率和客户粘性。

3.4 模块四：农产品加工（2级解锁）

核心逻辑：延长产业链，提升农产品附加值，减少损耗（滞销农产品可加工后售卖），由赵江新主导，玩家决策加工品类、产量，系统辅助管理加工流程。

3.4.1 加工品类（随公司等级解锁）

1. 初级加工（2级）：果干（草莓干、芒果干）、果酱（番茄酱、西瓜酱）、真空包装鲜食（水果玉米、小番茄），加工难度低，成本低，适合初期；

2. 中级加工（3级）：预制菜（蔬菜沙拉、玉米汁）、特色零食（玉米脆、番茄脆），加工难度中等，附加值高；

3. 高级加工（4级）：保健品（玉米肽、果蔬酵素）、礼盒套装（加工品+鲜品组合），加工难度高，利润高，需杨大振提供技术支持。

3.4.2 加工管理（躺平适配）

- 设备升级：消耗资金和生命源能，升级加工设备，提升加工效率、降低损耗，解锁新加工品类；

- 人员分工：招募村民担任加工工人，由赵江新管理，玩家只需支付工资，系统自动统计加工产量、成本；

- 损耗控制：系统实时监控加工过程，自动优化加工流程，减少农产品损耗，损耗率与加工设备等级、技术支持相关。

3.5 模块五：村民管理与共同富裕（贯穿全等级）

核心逻辑：公司发展与村民利益绑定，玩家通过“就业、分红、培训”带动村民增收，提升村民支持度，解锁共同富裕剧情，这是本玩法的核心目标之一。

3.5.1 村民招募与分工

- 招募渠道：通过刘怀均招募村民，公司等级越高，可招募人数越多（1级3人，5级50人以上）；

- 岗位分工：村民可分配至田间种植、加工、包装、发货、客服等岗位，玩家可自主分配，也可由系统自动分配（躺平模式）；

- 工资设置：玩家自主设置工资标准（基础工资+绩效），工资越高，村民积极性越高、流失率越低，影响工作效率和产品品质。

3.5.2 分红与激励机制

1. 季度分红：公司等级3级解锁，每季度从盈利中提取一定比例（玩家自定义，10%-50%）作为村民分红，分红比例越高，村民支持度提升越快；

2. 激励奖励：年度盈利达标后，给优秀村民发放奖金、奖品（如种子、农具、现金），提升村民积极性；

3. 股份合作：公司等级4级解锁，允许村民以土地、劳动力入股，成为公司合伙人，共享长期收益，彻底实现“村企共赢”。

3.5.3 新农人培训

- 公司等级5级解锁，与杨大振、赵江新合作，建立新农人培训基地，培训村民种植技术、电商运营、加工技能；

- 培训效果：提升村民工作效率、产品品质，解锁“村民自主创业”支线（部分村民学会技能后，自主开小店，代销公司产品），进一步扩大共同富裕覆盖面。

3.6 模块六：系统辅助与风险管控（全流程适配躺平）

核心逻辑：依托躺平智辅系统，降低玩家运营压力，实现“轻量化管理”，同时规避经营风险，保证公司稳定发展。

3.6.1 系统辅助功能

1. 数据统计：实时统计公司盈利、销量、成本、村民工资、农产品库存等数据，生成可视化报表，玩家可快速了解公司运营状态；

2. AI决策建议：系统根据市场行情、产品销量、村民状态，给出种植、加工、运营、分红等方面的建议，玩家可选择采纳或忽略；

3. 自动管理：开启“躺平模式”后，系统自动完成种植提醒、加工安排、直播运营、客户维护、工资发放等基础操作，玩家只需偶尔查看，无需每日操作；

4. 功能解锁：消耗生命源能，解锁“高级运营”“风险预警”“自动化加工”等功能，进一步降低操作难度。

3.6.2 风险管控（避免玩家经营失败，贴合躺平）

1. 市场风险：系统实时监控农产品市场价格，价格下跌时，自动提醒玩家调整定价、切换产品品类，或增加加工品生产，规避亏损；

2. 自然风险：农场遭遇自然灾害（旱灾、水灾、病虫害）时，系统提前预警，消耗生命源能可解锁“灾害防护”功能（如大棚防护、农药喷洒），减少损失；

3. 运营风险：出现村民流失、产品滞销、品质问题时，系统自动分析原因，并提供解决方案（如提高工资、开展促销、优化品质）；

4. 资金风险：系统实时监控资金流向，资金不足时，自动提醒玩家缩减开支、申请政府补贴（4级解锁），避免公司破产。

3.7 模块七：合作与拓展（3级及以上解锁）

核心逻辑：通过外部合作，扩大公司规模、提升品牌影响力，推动共同富裕目标落地，玩家决策合作方向，系统辅助完成合作流程。

3.7.1 核心合作对象

1. 科研合作：与杨大振、赵江新合作，开展作物品种优化、加工技术研发，解锁新作物、新加工品类，提升产品竞争力；

2. 政府合作：公司等级4级解锁，对接政府乡村振兴项目，获得政策扶持、资金补贴、品牌认证（如绿色食品、地理标志产品）；

3. 企业合作：与省城商超、餐饮企业、电商平台合作，签订长期供货协议，稳定销量；

4. 村集体合作：与刘家村及周边村庄合作，打造“乡村产业集群”，整合土地、劳动力资源，实现规模化、标准化生产。

3.7.2 拓展玩法

1. 线下体验店：公司等级4级解锁，在省城、县城开设线下体验店，展示、售卖农产品和加工品，提升品牌知名度，同时提供采摘、农耕体验服务；

2. 新农人孵化：公司等级5级解锁，孵化本村及周边村庄的新农人，提供技术、资金、渠道支持，帮助其自主创业，扩大共同富裕覆盖面；

3. 公益助农：与公益组织合作，帮助困难村民销售农产品、提供就业岗位，提升村民支持度，解锁公益结局支线。

四、资源与数值体系（关联游戏核心系统）

4.1 核心资源（与原有系统联动）

1. 资金：公司运营的核心资源，来源为农产品售卖、加工品售卖、政府补贴、合作收益，用于设备升级、工资发放、原材料采购、合作投入；

2. 生命源能：用于解锁公司功能、升级设备、技术研发、风险防护，来源为微粒兑换、任务奖励、剧情触发；

3. 微粒：基础资源，每日自动产出（随系统等级提升），可兑换生命源能、种子、加工原材料，来源为日常运营、任务完成、村民互动；

4. 村民支持度：影响公司等级升级、村民招募、合作解锁，来源为工资发放、分红、帮助村民、公益行为，降低会导致村民流失、运营效率下降；

5. 品牌知名度：影响产品销量、定价、合作机会，来源为直播运营、品牌认证、线下拓展、公益行为，提升可解锁高端渠道和高利润产品。

4.2 数值平衡（贴合躺平，避免过度肝）

- 盈利节奏：前期（1-2级）盈利较慢，以基础农产品售卖为主，后期（3-5级）盈利加速，加工品、高端渠道成为主要盈利来源；

- 升级难度：公司等级升级难度逐步提升，但系统辅助功能可降低操作难度，玩家可选择“躺平模式”缓慢升级，或“奋斗模式”快速升级；

- 资源获取：每日自动产出微粒、基础资金，任务奖励丰富，避免玩家手动刷资源；

- 风险平衡：风险预警及时，解决方案简单，即使玩家不手动干预，系统也能规避重大亏损，保证游戏体验。

五、任务与剧情联动

5.1 公司相关任务（主线+支线）

5.1.1 主线任务（推动公司升级）

1. 初创任务：注册公司、招募3名村民、完成首次加工品售卖，奖励：资金+5000，微粒+100，生命源能+2；

2. 成长任务：公司升级至2级、解锁2种加工品类、累计盈利50000元，奖励：品牌LOGO设计权限、直播流量加持功能、王楠好感+30；

3. 规模化任务：公司升级至3级、与杨大振达成科研合作、带动10名村民就业，奖励：AI运营辅助功能、高端包装解锁、村民分红权限；

4. 区域标杆任务：公司升级至4级、开设线下体验店、获得政府补贴，奖励：冷链物流合作权限、周边村庄收购权限、生命源能+10；

5. 共富任务：公司升级至5级、带动周边3个村庄发展、村民支持度满值，奖励：共同富裕终极剧情、系统终极功能、全成就解锁。

5.1.2 支线任务（丰富玩法，解锁剧情）

1. 村民支线：帮助村民解决就业、种植难题，解锁村民专属剧情，提升村民支持度和好感度；

2. 合作支线：与杨大振合作完成品种改良、与王楠合作打造直播爆款、与政府对接乡村振兴项目，解锁合作专属剧情和奖励；

3. 公益支线：参与公益助农活动、帮助困难村民，解锁公益结局，提升品牌知名度；

4. 感情支线：与王楠合作过程中，完成专属互动任务，解锁恋爱深化剧情（非强制，玩家可选择）。

5.2 剧情联动（贴合世界观）

- 与主角成长联动：刘洋从“想躺平”到“主动承担责任”，通过经营公司，实现“个人价值”与“社会价值”的统一，化解“躺平意愿”与“责任感”的矛盾；

- 与角色联动：王楠实现电商创业梦想，杨大振的科研成果落地，赵江新的技术得到应用，刘晓雪可通过公司获得就业机会（如客服、包装），实现经济独立；

- 与共同富裕联动：公司发展带动刘家村及周边村庄增收，改善农村基础设施，缩小城乡差距，最终触发共同富裕终极剧情，解锁终极结局；

- 多结局联动：根据玩家经营决策（如是否重视村民分红、是否开展公益、是否选择规模化发展），解锁不同结局（共富结局、品牌结局、公益结局、躺平创业结局）。

六、UI与交互设计（贴合文字类游戏，轻量化）

6.1 核心界面（简洁、易操作，适配手机端）

6.1.1 公司面板（核心界面）

- 顶部：公司等级、品牌知名度、村民支持度、当前资金、生命源能、微粒；

- 中部：核心模块入口（农场管理、电商运营、加工车间、村民管理、合作拓展）；

- 底部：任务提醒、系统消息、设置（可开启/关闭躺平模式）。

6.1.2 各模块界面

- 农场管理：显示种植作物、生长状态、种植模式，可一键开启系统辅助种植；

- 电商运营：显示各平台销量、直播计划、产品库存，可选择直播主题、定价策略；

- 加工车间：显示加工品类、产量、设备状态，可升级设备、分配加工任务；

- 村民管理：显示村民列表、分工、工资、好感度，可招募、分配岗位、发放分红；

- 合作拓展：显示可合作对象、合作进度，可发起合作、查看合作收益。

6.2 交互逻辑（贴合躺平，减少操作）

1. 轻量化操作：所有核心操作（如种植、直播、加工）均可选择“系统自动完成”，玩家只需做决策，无需手动重复操作；

2. 即时反馈：操作后立即显示结果（如盈利到账、村民支持度提升、产品解锁），提升游戏反馈感；

3. 快捷入口：常用功能（如系统面板、任务、村民管理）设置快捷按钮，一键进入；

4. 存档读档：支持手动存档、自动存档，可随时回溯决策，调整经营方向。

七、玩法亮点与差异化

7.1 核心亮点

1. 躺平与奋斗平衡：玩家可选择“躺平模式”（系统自动管理）或“奋斗模式”（手动深度运营），兼顾低压力与策略性，适配不同玩家需求；

2. 全产业链闭环：从种植、加工到电商销售、村民共赢，形成完整玩法闭环，贴合乡村电商真实逻辑，兼具趣味性与现实意义；

3. 共同富裕落地：玩法核心围绕“带动村民增收”，村民管理、分红、培训等玩法，让“共同富裕”不再是口号，而是可落地的游戏目标；

4. LLM适配性强：玩家可自定义经营决策（如种植品类、合作方向、分红比例），LLM可根据玩家选择，生成个性化剧情、事件、收益结果，提升自由度；

5. 角色深度联动：所有核心角色都有明确的岗位和剧情，玩家经营决策会影响角色成长和剧情走向，提升沉浸感。

7.2 差异化优势

- 区别于传统农场经营游戏：不侧重手动种植操作，而是聚焦“电商运营+村企共赢”，突出乡村振兴、共同富裕的核心主题；

- 区别于传统电商游戏：以农场为核心供应链，强调“原生态、本地化”，联动种植、加工玩法，内容更丰富；

- 区别于普通文字游戏：有完整的经营数值体系、系统辅助功能，玩法性更强，同时保留文字剧情的沉浸感。

八、开发与优化建议

8.1 开发重点

1. 系统联动：确保电商公司玩法与原有躺平智辅系统、角色系统、资源体系无缝衔接，避免数值冲突；

2. LLM适配：优化LLM剧情生成逻辑，根据玩家经营决策，生成合理的剧情、事件、收益，保证剧情连贯性和逻辑性；

3. 轻量化运营：重点优化“躺平模式”，确保系统自动管理功能流畅，减少玩家手动操作，贴合游戏核心定位；

4. 数值平衡：合理设置公司升级条件、盈利节奏、资源获取速度，避免玩家过度肝或经营失败，保证不同玩家的游戏体验。

8.2 优化方向

1. 新增个性化内容：允许玩家自定义公司LOGO、产品包装、直播风格，提升个性化体验；

2. 丰富事件系统：新增随机事件（如市场波动、政府扶持、村民突发情况），提升玩法趣味性；

3. 拓展结局分支：根据玩家经营策略，新增更多结局（如失败结局、小众创业结局），提升游戏 replay 价值；

4. 强化社交玩法：新增玩家之间的合作、竞争（如共建产业集群、电商比拼），提升游戏互动性。

九、总结

本玩法以“农场电商公司”为核心，贴合《躺平农场主：共同富裕计划》的世界观和核心目标，实现了“躺平低压力”与“经营策略性”的平衡，构建了“种植-加工-电商-共富”的全流程闭环。玩法联动现有角色、系统、资源，适配LLM生成逻辑，既允许玩家轻松躺平、享受游戏，也支持玩家深度运营、实现共同富裕的目标，同时突出乡村振兴、村民共赢的现实意义，为游戏中期至后期提供丰富、可落地的核心内容。
