### 关键数据流

```
用户界面 (story_panel.html)
   ↓ 用户点击指令
POST /api/story/execute-command
   ↓ 接收请求
Flask 路由处理
   ↓ 调用 GameEngine
engine.play_open_mode_action()
   ↓ 调用 LLM API
LLM 生成故事和stat变化
   ↓ 计算 delta
save_game() 保存状态
   ↓ 组织 JSON 响应
返回 {"success": true, "result_text": "...", "stat_changes": {...}}
   ↓ 前端 AJAX 接收
JavaScript 更新 UI
   ↓ 动画展示结果
用户看到故事和数值变化
```
